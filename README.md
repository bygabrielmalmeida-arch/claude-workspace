# claude-workspace

Repositório geral para trabalhar com o Claude Code: skills, sites e experimentos.

## Skills incluídas (`.claude/skills/`)

- **ui-ux-pro-max**: inteligência de UI/UX (estilos, paletas, fontes, guidelines). Fonte: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- **sites-premiados-tedson**: gera sites HTML de página única com GSAP, Lenis, SplitType e Three.js.

Toda sessão do Claude Code aberta neste repositório carrega essas skills automaticamente.
